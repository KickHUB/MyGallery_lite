# PNG 무결성 샘플 조치 가이드

데이터 탭의 무결성 진단 샘플(no_meta, no_ksampler, missing_positive, read_failed)에 대해
원인과 권장 조치를 정리했습니다.

## no_meta
- **원인**: PNG에 메타데이터가 저장되지 않았거나, 저장 과정에서 메타가 손실/손상되었습니다.
- **권장 조치**
  1. 원본 생성 워크플로에서 이미지를 **재생성**합니다.
  2. 기존 파일에 메타를 다시 기록할 수 있다면 **메타 재추출/재주입**을 시도합니다.
  3. 재생성/재주입 후 **PNG 무결성 검사**를 다시 실행해 확인합니다.

## no_ksampler
- **원인**: 워크플로 메타에 KSampler 노드 정보가 기록되지 않았습니다.
- **권장 조치**
  1. 원본 워크플로(JSON)를 확인하고 **KSampler 노드가 포함되었는지** 점검합니다.
  2. 문제가 있는 경우 워크플로를 **재내보내기** 또는 **재생성**합니다.
  3. 메타 재추출 후 **무결성 검사**로 재확인합니다.

## missing_positive
- **원인**: 긍정 프롬프트가 누락/비어 있거나 추출 단계에서 파싱이 실패했습니다.
- **권장 조치**
  1. 원본 프롬프트 텍스트를 확보하고 **메타에 다시 기록**합니다.
  2. 프롬프트가 없는 파일은 **원본 재생성**을 권장합니다.
  3. 수정 후 **무결성 검사**로 반영 여부를 확인합니다.

## read_failed
- **원인**: 파일 손상, 권한 문제, 파일 잠금 등으로 읽기에 실패했습니다.
- **권장 조치**
  1. 파일 권한/잠금 상태를 확인합니다.
  2. 손상된 파일은 **삭제 후 재생성** 또는 **백업 복원**을 진행합니다.
  3. 조치 후 **무결성 검사**를 다시 수행합니다.
